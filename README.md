# AEROCHARGE Kiosk

1080×1920 세로형 충전기 키오스크를 위한 정적 웹 데모입니다.

## 기능

- 충전량, 출력, 전압, 전류, 온도 실시간 시뮬레이션
- 충전 시작·일시정지·종료 터치 조작
- 목표 충전량 80%·90%·100% 설정
- 출력·열관리·시스템 분석 화면 전환
- 키오스크용 전체 화면 버튼
- 1080×1920 세로 화면 우선 반응형 레이아웃

## 실행

별도 빌드 없이 `index.html`을 열거나 정적 웹 서버로 실행하면 됩니다.

```bash
python3 -m http.server 4173
```

## 배포

GitHub Pages의 `main` 브랜치 루트에서 바로 서비스할 수 있습니다.
